## 6. Decisions made, and why

- **Illustrations come from ChatGPT, one image per conversation** (Mathi,
  2026-10-02). Supersedes the 2026-10-01 Claude-app decision; in the KB.
- **Homepage share image is a static screenshot of the hero** (Mathi found the
  drawn card bland). Retake it when the hero changes: headless Chrome at
  1440x756, device scale 2, scale to 1200x630. Listings and articles keep the
  drawn `/deling/…` cards from `PollPreview`.
- **Homepage title "Find en dag, der passer alle – Kanvi?"** (Mathi's wording;
  en dash, question mark echoes the logo). Feeds `og:title` too. Other pages
  keep "| Kanvi" or "· Kanvi".
- **`fb:app_id` warning in the Sharing Debugger is ignored**: only needed for
  Facebook apps and Insights, not link sharing.
- **PageSpeed's render-blocking Livewire warning is left alone** (Mathi).
  Lighthouse 12 mobile: home 95 (LCP 2.7 s), /til/venner 100; Brotli and long
  caching already on. If revisited: bundle the Livewire ESM into `app.js` with
  `@livewireScriptConfig`; the script cannot be dropped because the homepage
  demo poll uses the Alpine that ships with Livewire.
- **Headlines and long sentences go in page text, not in images** (working
  choice): ChatGPT misspelled or malformed them. Pixel-only fixes (cut a
  letter, paint over a row, crop) were applied to originals; no text drawn in.

## 8. Traps in this repository

- **A push is a deployment.** CI runs on every branch; only `main` deploys.
- `/deling/{article}` accepts only `ArticleController::shareKeys()`; static
  `.png` paths are served by the host and never reach PHP.
- The image test asserts exact per-article counts and real 390/720 variants.
- Every page logs a Chrome "issue" (not error) about lazy-loaded image
  dimensions although images carry width, height and aspect-ratio.
  Pre-existing, not investigated.
- Inline SVG logos contain `<title>Kanvi?</title>`; a grep for `<title>` finds
  them besides the page title.
- Product UI must be a real screenshot (`docs/indhold/PUBLICERING.md`).
- Retention, recovery-mail, funnel and secrets rules: see `AGENTS.md`.
